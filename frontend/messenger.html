Начнём сначала

Старая база лидов очищена. Дальше система ищет не «ещё названий», а бизнесы, до которых можно достучаться и у которых есть что чинить.

    1

    Ключ Google — 5 минут, один раз

    Нужен, чтобы система нашла сайт бизнеса, когда его нет в карточке. Без ключа адрес известен примерно у четверти лидов, с ключом — у большинства. Это самый недооценённый шаг: он один поднимает отдачу всего парсера.

    Ключ личный. Квота считается на ключ: 100 запросов в сутки бесплатно. Общий ключ один человек сжёг бы за один прогон. Хранится зашифрованным, коллеги его не видят, удалить можно в любой момент.

    1. Создайте проект: console.cloud.google.com/projectcreate → любое название → Create.
    2. Включите Custom Search API: страница API → Enable.Пропустите — ключ будет отвечать ошибкой 403.
    3. Создайте ключ: Credentials → Create credentials → API key. Строка вида AIza….
    4. Создайте поисковую систему: programmablesearchengine.google.com → включите «Search the entire web» → Create.Без «весь интернет» поиск ищет только по указанным сайтам и не находит ничего.
    5. Скопируйте Search engine ID (cx) со страницы Overview.
    6. Вставьте оба значения в карточке Google в разделе «Интеграции» → Перевірити й зберегти.
    2

    WhatsApp и Instagram

    Нужны, только если пишете клиентам прямо из системы. Поиск и диагностика работают и без них.

    Для WhatsApp Business — Phone Number ID и Access Token из кабинета Meta; для Instagram — Instagram User ID и токен оттуда же. Токен проверяется при подключении, а кнопка «Перевірити» покажет, что он истёк, раньше, чем вы потеряете переписку: временные токены живут сутки.

    Каналы личные: чужие подключения вам не видны и отключить их нельзя.

    3

    Поиск клиентов

    Раздел Пошук клієнтів: страна, город, категория — система собирает бизнесы и кладёт их в базу лидов.

    • OpenStreetMap — бесплатно и без ключа. Хорошо покрывает Европу, хуже остальной мир.
    • Google — работает с вашим ключом, находит тех, кого нет в OSM, и чаще даёт сайт.

    Данные OSM заполняют люди, поэтому «нет сайта» там — предположение, а не факт. Точный ответ даёт диагностика на следующем шаге.

    4

    Диагноз лида — главное место

    У каждого проверенного лида есть диагноз и доказательство: код ответа, дата сертификата, кусок страницы. Доказательство — это первая фраза вашего сообщения. Не «у вас плохой сайт», а «с 3 августа ваш сайт отдаёт ошибку 502».

    ДиагнозЧто случилосьО чём писать
    dead_dnsДомен не существует или не настроенСайт не открывается ни у кого — самый сильный повод
    unreachableДомен есть, сервер молчитТо же, но перепроверьте через день
    http_5xxСервер отвечает ошибкойСайт сломан прямо сейчас
    tls_expiredСертификат просроченБраузер пугает посетителей красным экраном
    parkedЗаглушка регистратора или дефолтная страницаДомен куплен, а сайта нет
    placeholder«Coming soon» или пустая страницаСайт обещан, но не сделан
    broken_shopМагазин есть, корзина отдаёт ошибкуЛюди не могут купить
    blockedНас не пустила защита от ботовНе повод писать. Проверьте руками
    domain_unknownМы не нашли адрес сайтаЭто не значит, что сайта нет. Нужен ключ Google
    okСайт работаетТехнического повода нет — ищите другой

    Два диагноза никогда не превращайте в претензию: blocked и domain_unknown. В первом случае сайт скорее всего в порядке, во втором мы просто не знаем адреса. Написать «у вас нет сайта» тому, у кого он есть, — потерять клиента навсегда.

    5

    Ежедневная работа

    • Мій день — кому пора написать или ответить. Начинайте отсюда.
    • План контактів — норма 5 лидов в рабочий день.
    • Воронка — карточки по стадиям: Новый → Связались → Ответил → Предложение.
    • Ліди — весь список с фильтрами по владельцу, стадии, стране, диагнозу и баллу.

    Как добавить лида себе: назначить на себя прямо из результатов поиска; открыть карточку и поставить себя владельцем; добавить вручную в разделе «Ліди», если клиент пришёл сам.

    Заметки в карточке видит вся команда — это общая память по клиенту. Для себя есть отдельное личное поле.

    Балл складывается из понятных слагаемых, и рядом всегда написано, из каких: есть WhatsApp, сломан сайт, нет магазина. Балл выглядит странно — разверните объяснение.

    Границы, которые мы не переходим

    • Не читаем Instagram и Facebook. Профили за логином, обход нарушает правила Meta и подставляет компанию. Берём только то, что бизнес сам выложил в открытый интернет.
    • Не проверяем номера в WhatsApp. Значок ставится, только если бизнес сам разместил кнопку чата на сайте.
    • Не обходим капчи и защиту. Не пустили — лид помечается blocked, а не «сломан».
    • Не выдумываем данные. Пустое поле значит, что источник молчал. Пустота честнее правдоподобной догадки.

    Если что-то не работает

    Ключ не сохраняется, ошибка 403
    Не включён Custom Search API — шаг 2 в разделе про ключ.
    Ключ сохранился, но поиск ничего не находит
    В поисковой системе не включён режим «Search the entire web».
    «Дневную квоту исчерпано» (429)
    Ключ рабочий, 100 бесплатных запросов на сегодня кончились. Завтра продолжит работать.
    Много лидов с domain_unknown
    У них нет ни сайта, ни рабочей почты в карточке, а ключ Google не подключён. Подключите — большинство получит нормальный диагноз.
    Сообщение не уходит в WhatsApp
    Скорее всего истёк токен. Интеграции → «Перевірити» покажет причину.

    Для администратора

    Этот раздел видят только администраторы. Менеджерам он не показывается.

    Что произошло с базой

    Старая база из 1183 лидов очищена: 1132 карточки никто никогда не трогал. Сохранена 51 — те, у кого есть движение по воронке или живая заметка человека. Полная копия базы и отдельный JSON-дамп лежат на сервере в /opt/army-bank/backups/, восстановление точечное.

    Как запускать диагностику

    Прогон делается скриптом на сервере, а не через интерфейс: он долгий и gunicorn убил бы его по таймауту.

    cd /opt/army-bank
.venv/bin/python backend/scripts/leads_diagnose.py \
  --db database/army_bank.db --diagnose --limit 100 --user 5
    • --user 5 — прогон ключом Миши, --user 6 — Едуарда. Без него поиск доменов выключен.
    • --stats — сводка без изменений.
    • --all — перепроверить и тех, у кого диагноз уже есть.
    • --purge — чистка с сохранением проработанных, --purge-all — снести всё.

    Перед любой чисткой делайте копию: скрипт удаляет без подтверждения. Копия — sqlite3.backup, а не cp живого файла.

    Кому что подключать

    Ключ Google и каналы подключает каждый сам под своей учётной записью — токены и ключи привязаны к человеку. Администратор не может подключить ключ за менеджера, и это намеренно: квота и ответственность за токен персональные.

    Как понять, что всё работает

    Смотрите на долю лидов с диагнозом и на domain_unknown: если он выше половины, значит у менеджера не подключён ключ. Метрика качества — не количество лидов, а ответы на сотню сообщений.
