Режим Презентаційний приховує низькорівневі технічні деталі та залишає тільки ключові сигнали стану API.

Як читається перевірка

ok означає HTTP 2xx, auth — endpoint працює, але потребує доступу, warn — потрібна ручна увага, bad — помилка.

Що означає manual

manual ставиться для маршрутів, які не можна безпечно дергати автотестом (не-GET або path-параметри).

Uptime-стрічка

Лента зберігає останні 48 перевірок /health у браузері, щоб відразу бачити стабільність між релізами і cold-start.

Для чого фільтри

Фільтри по методу, стану та path прискорюють діагностику: можна швидко ізолювати лише критичні або лише auth-ендпоінти.
